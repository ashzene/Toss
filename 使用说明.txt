1. 在 Mac 的「设置 Toss」引导中，用 USB 数据线配对 iPhone，再完成无线连接。「iPhone 轻点背面」这一步会显示添加和配对捷径的方法。可以点「跳过」继续到「试一下」，以后从 Toss「设置 → 更多… → iPhone 快捷指令… → 在 iPhone 上设置…」设置。

此前0.4.0 build12已经安装，用户确认可用；同版白底PDF两次726ms、662ms，约10.5MiB的大图两次2010ms、2246ms。这里是日志从定位到确认附件的时间，不是独立物理按键到屏幕计时。0.3.0另有13次成功732–1029ms，以及更早的无线失败和未确认事件。不同图片负载不能直接当作版本性能差异。
0.4.2的用户实测已确认自动恢复和截图追加，但附件位置未取得，飞入未触发。0.4.3继续修复渲染器中未带role/filename的匿名预览卡片定位，仅从已确认的唯一删除按钮的现有短祖先链找已证实卡片类名；不猜位置。
本0.4.3保留已验证的截图后端、配对、画质、登录恢复和成功音，只调整视觉衔接与用户连续操作处理。构建时尚未真机验收；最新安装/用户触发结果以INSTALL-STATUS和诊断记录为准。
每次按键仍只调用一次新的截图RPC，不预取图片、不连续录屏。启用或恢复时预先建立认证连接及截图通道，但不调用截图；连接成功或分享成功后最多空闲保留10分钟。错误、取消、超时或断线会销毁不确定的通道，不重试同一次截图。
提示音（2026-10-24 Ashley选定）：成功音为“抛出去”（Toss-Success.aiff），只有确认原生附件后才播放；失败音为“低音敲两下”（Toss-Failure.aiff），只在按键后取图或粘贴失败时播放一次，自己打字或点击造成的取消保持安静。先响声音，再显示提示框和输入框里的果冻动画。App里不再带Codex的声音。
已有聊天仍通过同一窗口/页面、真实线程行专用类标记、所属列表和aria-current=page识别；新对话使用上述独立首页草稿分支。缺少明确证据就停止，不点击或切换侧栏聊天。

首次安装（你操作）
1. 打开磁盘映像中的 Toss.app，按应用内引导安装到「应用程序」；安装.command 仅打开随附的 Toss.app。
2. Python 和依赖已内置在 App 中，无需另装运行环境。本版本不自动导入以前安装的数据。
3. 打开安装后的 Toss.app，按引导连接设备并完成配对与授权。完成设置后默认静默驻留菜单栏；从菜单栏打开设置，关闭设置窗口不会退出工具。
4. 在设置窗口点击“设置辅助功能…”和“设置输入监控…”，会打开对应系统设置页；按系统提示在“系统设置 → 隐私与安全性”授权这个工具。输入监控授权后退出并重新启动工具。若系统询问本地网络访问，也需要允许本工具／其 Python 进程访问同一热点。没有绕过权限或修改 TCC 数据库。
5. 这是本机临时签名，未经过 Developer ID 公证。若系统阻止打开，可用 Finder 的“打开”及系统提供的正常确认流程；不要关闭 Gatekeeper 或系统完整性保护。
窗口会分别显示辅助功能、输入监控和按键发送的当前权限状态；“未就绪”不等于永久拒绝。系统可能不重复弹出提示，请在对应设置页开启工具的开关。列表没有工具时，用＋添加 ~/Applications/Toss.app。授权后退出并重新打开工具。
6. 先打开新版 ChatGPT／Codex，再由你亲自点击工具的“启用左右 Option”。工具会请求目标应用公开的 AXEnhancedUserInterface 模式并等待约2.5秒，让框架生成完整的辅助功能属性；并在后台预先建立已配对设备连接和截图通道，不截图；不改窗口、草稿或磁盘配置。框架可能报告“可写”却由super返回“未实现”；本工具仅对这一已观察组合等待，并把准备结果标为不确定，不当作识别成功。当前聊天实际标记仍必须通过。显示“已启用”说明监听已开启，之后可关闭设置窗口。首次成功启用会记住状态并尝试注册登录项；系统若要求批准，工具会显示真实状态，请在系统设置 → 通用 → 登录项中允许。安装脚本本身不启动工具、不注册登录项。

记住启用与登录自启
• 首次成功启用后保存意图；退出后再次运行会自动恢复，不必每次点启用。登录时自动运行是独立开关，可在工具设置/菜单中关闭。
• 你主动“停用”会清除自动恢复意图；“退出”保留它。取消登录自启不会停掉当前监听，也不会清除手动启动时的恢复意图。后续点启用不会擅自重新打开你取消的登录项。
• 已设置过的工具启动保持静默，包括“保留登录项但停用快捷键”的情况。目标尚未启动时等待其启动/激活事件；权限不齐只显示状态，不自行弹权限框。用户打开工具或刷新权限时可继续恢复。
• 目标应用退出会取消当前操作；重新启动后根据保存意图重新准备。恢复只准备连接和监听，不截图、不聚焦输入框、不粘贴。Mac唤醒也不会自动取图。
• 更新临时签名仍可能需要刷新本工具授权；保存启用状态无法替代系统权限。登录项注册、真实注销/登录、目标晚启动等行为需真机验证。

日常使用
• iPad 使用前解锁，Mac 和 iPad 连同一 Wi-Fi 或第三台 iPhone 热点（Mac 也可用网线接同一个路由器）；不需要 USB，不启动 ReplayKit 广播或投屏窗口。
• 在 ChatGPT／Codex 打开想接收截图的聊天。目标 App 前台时使用其当前聚焦窗口；焦点在其他 App 时，只接受唯一可见且未最小化的 ChatGPT／Codex 窗口。后台有多个候选窗口则拒绝，需把目标窗口带到前台，不能猜最近聊天。
• 同时按左右 Option，然后完全松开。按住不会重复；两键都松开后才能再次触发。截图期间切换聊天、改草稿或切换前台 App 会取消这次操作；再次按不会排队。
• 成功时会把 ChatGPT／Codex 及其目标输入框带到前台。这会改变键盘焦点；你可继续输入后自己发送。
• 右下角显示获取状态和真实缩略图。确认原生附件后，如果同一辅助功能树已明确暴露本次唯一附件卡片及其实际框，缩略图用约0.32秒飞入该位置并淡出，接回原生附件。此为独立覆盖层的视觉衔接，没有修改ChatGPT原生插入动画；覆盖层不激活、不接收鼠标或键盘。
• 飞入不阻塞粘贴/声音，不等待图片解码；额外可选位置查询预算25ms，失败只跳过飞入。缩略图只用于反馈，原始附件不压缩、不裁切。缺少位置/缩略图、源与目标不同屏、减少动态效果等情况，保留角落淡出。后续点击、滚动、普通按键、切换应用、新请求都会取消正在飞行的装饰，防止删除原图后装饰残留。真实AX暴露、视觉和多屏/全屏效果待用户验证。
• 可以连续按双Option：一次未完成时的新组合被消费，不排队、不额外截图；粘贴前若新一轮Option仍按着，异步等松键，最多到原截图有效期。等待后仍核验同一聊天/草稿/焦点。若用户编辑文字或删除原附件，本次安静取消，不播放错误音；下一次新组合重新取当前画面。
• 粘贴后的只读确认不再要求输入框一直占焦点，点击附件删除按钮不会仅因焦点移动而报错；粘贴前仍严格要求正确焦点和空选区。若新增图片出现后在两次读取间被删掉，工具无法证明其出现过：保留最多8秒确认期和忙碌状态，随后静默结束，诊断记录为追加未确认，不播放成功音、不补发。窗口/聊天不明、未知或重复附件、设备/网络错误仍停止操作，并保留真实失败诊断。
• 只有确认原生附件已出现后，播放一次“抛出去”成功音；取图、请求粘贴、失败或未确认时不播放成功音。按键失败时播放一次“低音敲两下”失败音。
• 菜单栏“iPad …”表示处理中。失败或未确认会安静回到普通待机显示，不弹窗、不响错误音、不显示失败卡片或感叹号。需要排查时由你主动打开“查看诊断”。工具不会自动重试可能已发生的粘贴。

草稿与剪贴板
侧栏行、所属列表、窗口和输入框在一次请求中保持同一对象；截图后、聚焦后和粘贴前都会重新检查。行被替换、重新挂载或不再是当前聊天时停止；同名聊天不会仅因标题相同而被认为是同一条。
工具不写 AXValue、不按 Command-A、不删除附件。它在内存保存原文字及附件标记，追加前复核，追加后要求原文字不变、旧标记保留，并出现本次唯一 PNG 文件名的附件标记。
如果输入框有选中的文字，或无法确认选区为空，会停止，避免替换文字。
它临时把 PNG 文件 URL 写到系统剪贴板，让原生 App 按普通文件粘贴处理，不会粘贴纯路径文字。确认附件后恢复原剪贴板；若同一聊天已明确出现本次唯一文件名，但你同时修改了文字/旧附件，仅确认粘贴已消费并安静停止，允许恢复原剪贴板，不宣称草稿追加完整成功。如果你或别的 App 已更改剪贴板，则不覆盖新内容。
如果粘贴已请求但未确认，剪贴板会保留本次截图，避免排队中的粘贴读到原先的内容。请检查草稿，不要立即连按重试。0.1.5的原生文件URL追加及对应唯一文件名已由用户触发的两次日志确认，用户看到图片；缩略图删除、复杂附件类型等仍待完整验收。

准确的限制
• macOS 的“检查后再发按键”不是与目标 App 共享的原子事务。工具多次复核并向确定进程发键，仍不能在未实测时保证所有极短窗口／聊天切换竞态都已消除。
• 旧版依赖页面 URL；本版为内存路由增加当前线程行识别。已核对本机应用源码与 Chromium 的 AXDOMClassList、AXARIACurrent 实现，0.1.5用户实测已出现唯一当前聊天标记；跨聊天切换等仍需要用户触发验收。侧栏收起、当前聊天不在已呈现列表中、行重挂载、同一聊天在多个区域同时被标为当前时可能拒绝。找不到时不猜坐标或最近聊天；新对话必须独立通过首页证据核验。
• 后台多窗口、输入框选区不可读、复杂页面超过读取预算会拒绝；这不是完整多窗口支持。
• 原生 App 可能改名附件；如果不能精确确认这次 PNG，显示“未确认”，不会当作成功或再次粘贴。
• iPadOS 18.7.8 的可靠锁屏查询不支持；请确保使用前及取图期间保持解锁。工具拒绝全黑、空、错误尺寸及过期结果，但不能可靠识别非黑锁屏画面或局部受保护内容。
• 每次请求新帧，不读取旧截图作回退；没有设备帧时间戳，不能证明画面精确对应按键那一毫秒或排除所有设备内部缓存情况。
• 设备重启、开发镜像重新挂载、长时间待机、换热点和全部断线情形，仍需真实验收。没有升级 iPadOS。
• 完整辅助功能准备每个目标进程只请求一次，不在截图中途或每次核验重复请求。0.1.5用户启用后实测已可读取当前聊天标记；如果目标应用重启，保存的启用意图会等待其重新启动并再次准备；无法自动恢复时可在工具中查看状态。停用时不自动关闭这个模式，避免影响其他辅助工具；重启目标应用会重建其运行时状态。
• 本机没有可用的正式代码签名身份；此工具仍为临时签名。更新二进制后，旧授权记录可能不匹配，需仅为本工具移除旧条目并重新添加当前安装路径；不要反复新建或选择多个版本。
• 没有修改 ChatGPT 的应用包、签名、配置或聊天数据库。运行时通过你授权的公开 macOS 辅助功能、剪贴板及键盘事件接口工作。

你运行后的验收建议
先在一个测试聊天留一段可辨认文字，并已有一个附件。按双 Option，确认旧文字、旧附件仍在，新图能预览／删除，且消息未发送。然后依次测试 PDF手写、Safari普通网页、横竖屏、焦点在其他 App、前台多窗口／聊天切换、按住只一次、普通 Option 组合键及原生左右 Command、断网和锁屏失败。失败后可点击“查看诊断”；它不含聊天文字、截图或设备密钥，也不会改剪贴板。
不要把菜单里的“目标检查通过”当作图片追加成功；它只证明当次定位检查。

隐私与文件
只有触发时才请求一张图。iPhone 快捷指令开启后，Mac 在局域网内接收经配置认证的触发请求，截图仍通过 Toss 已认证的设备连接传输。Python 子进程通过父子匿名管道收发指令。启用时可预连接，连接建立或成功贴图后最多空闲保留 10 分钟已认证连接，期间仅维持连接。停用时关闭截图连接。退出或 Mac 休眠时也关闭 iPhone 快捷指令的接收端，唤醒后等待下一次触发。
配对副本：~/Library/Application Support/Toss/DeviceState（目录0700、文件0600）。不得分享这个目录。
截图缓存：~/Library/Caches/Toss/Captures（0700）。未发粘贴的失败截图清理；发过粘贴的图片保留最多至后续启动清理24小时前文件，以免原生 App 尚未读取。退出后可自行清除此目录；可能含你的题目／笔记，默认不会打入源码包。
运行中原文、聊天行标题和附件标记仅保存在进程内存。诊断摘要只含状态、权限布尔值、固定类型、计数、连接是否复用、毫秒耗时和经过筛选的错误类别／后端原因码，不含聊天标题、文字、URL、聊天ID或截图。
每次触发的最近20条阶段记录会写入 ~/Library/Application Support/Toss/last-run.json（0600），可用设置窗口的“查看诊断”阅读；查看不会查询目标 App、请求截图或改剪贴板。“复制诊断摘要”才会主动改变剪贴板。卸载本工具时也删除这份诊断。

停用／卸载
菜单“停用左右 Option”立即停止监听、取消正在取图并清除自动恢复意图；菜单“退出”结束程序但保留启用意图。要停止下次登录运行，再关闭“登录时自动运行”。已投递的粘贴不能可靠撤回，取消后仍应检查草稿；工具不会删除已添加附件。
在 Toss 的「设置 → 卸载 Toss…」中点「卸载」。Toss 会停止截图和配对进程，尝试注销登录项，删除本机配对文件、设置和截图缓存，再把自身 App（含内置 Python 环境）移进废纸篓并退出。某一步失败仍继续后续清理；若 App 无法移入废纸篓，会在 Finder 中选中它并提示「请把 Toss 拖进废纸篓」。辅助功能权限会保留，重新安装后可以直接用；要删的话在「系统设置 → 隐私与安全性 → 辅助功能」里移除。
卸载不撤销 iPad 端或原无线组件的既有配对，不关闭开发者模式。精确设备端 RemotePairing 撤销尚未验证；不要把重置全部信任当作本工具常规卸载。
