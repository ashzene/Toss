Wireless transport provenance

vendor/remote_pairing_transport.py and vendor/system_bonjour.py are derived from
an earlier, device-tested local prototype. On 2026-10-15 the companion copies gained a
dual-stack DNS-SD settle optimization and per-request endpoint deduplication;
they are no longer byte-for-byte copies. These two changes have synthetic test
coverage but no new real-device timing validation. Authentication, route checks,
timeouts and screenshot freshness checks were not weakened.
The companion exposes only the Wi-Fi capture
entry point. The transport module retains its original initial USB bootstrap
implementation for source fidelity, but capture_once.py never calls it and no
bootstrap command is exposed by this backend.

vendor/ipad_probe.py contains only the original ProbeFailure and fingerprint
helpers. vendor/wifi_transport.py contains only the host LAN interface lookup
(Wi-Fi first, then active Ethernet), extended from the original wifi_interface
helper. Older direct-lockdown/USB transport and setup commands are not included
in these minimal support modules. No upstream files were modified.
